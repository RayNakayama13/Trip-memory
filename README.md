# Trip Memory｜旅の思い出アルバム

写真をアップロードするだけで、**いつ・どこで・何をしていたか**を地図と時系列で振り返れる Web アプリです。

iPhone などで撮った写真に埋め込まれている EXIF（撮影日時・GPS 座標）を読み取り、
旅ごと・日ごと・立ち寄り先ごとに自動でまとめ直します。

## できること

- **写真を入れるだけ** — ドラッグ&ドロップ、またはファイル選択でまとめて取り込み
- **旅ごとのアルバム** — 撮影の間隔から旅の区切りを見つけて、アルバムに自動で振り分け
- **アルバムの命名** — 名前はあとからいつでも変更でき、メモも残せる
- **アルバムの出し入れ** — 空のアルバムを自分で作る、写真を別のアルバムへ移す、アルバムを消す
- **立ち寄り先の自動抽出** — 時間の空きと移動距離から「どこに寄ったか」を推定
- **地名の自動取得** — 座標から場所の名前（例: 清水寺）を取得して見出しに
- **行動の推測** — 場所の種別と時間帯から「ランチ」「観光」「温泉」などのラベルを付与
- **地図で見る** — 立ち寄り先を順番付きのピンで表示し、移動の線でつなぐ
- **時系列で見る** — 1日目・2日目…と日ごとに並ぶタイムライン。ピンと相互に連動
- **写真ビューア** — クリックで拡大、左右キーで移動
- **自由に書き換え** — 旅・立ち寄り先のタイトルとメモはその場で編集可能
- **HEIC 対応** — iPhone の HEIC/HEIF は必要なときだけ変換モジュールを読み込んで表示
- **iPhone で使える** — ホーム画面に追加すればアプリのように全画面で起動。オフラインでも見返せる

## プライバシー

**写真はどこにもアップロードされません。** 取り込み・縮小・EXIF 解析はすべてブラウザ内で行われ、
写真とメタデータは端末の IndexedDB にのみ保存されます。

外部通信は次の 2 つだけです。

- 地図タイル（OpenStreetMap）の取得
- 地名の取得（OpenStreetMap Nominatim へ**座標のみ**を送信。設定画面からオフにできます）

## アルバムの考え方

アルバムは「ひとつの旅」の入れ物です。写真を取り込むと、撮影日時が近いものが同じアルバムに入ります。

- **後から写真を足したとき** — 既存アルバムの期間に近ければ、そのアルバムに合流します
  （旅の写真を分けて取り込んでも、アルバムが分裂しません）
- **別の日の旅** — 新しいアルバムが自動で作られます
- **アルバムの中から追加したとき** — 日付にかかわらず、そのアルバムに入ります
- **名前** — 付けるまでは地名と日付から作った仮の名前が出ます（「仮の名前」バッジ付き）
- **未整理の写真** — 撮影日時が読み取れなかった写真や、アルバムから外した写真がここに集まります

立ち寄り先や日ごとのまとまりは、アルバムの中で自動計算されます（写真を足すたびに計算し直されます）。

## iPhone で使う

公開先の URL を Safari で開き、共有ボタン → **「ホーム画面に追加」**。
アプリと同じように全画面で起動し、一度開いたあとはオフラインでも見返せます
（`https://` で配信されている場合）。

写真は「写真を選ぶ」から**フォトライブラリを直接選択**できます（複数選択可）。
位置情報が入るように、iPhone の **設定 > プライバシーとセキュリティ > 位置情報サービス > カメラ** を
「次回確認」ではなく許可にしておいてください。

スマートフォンでの操作は次のとおりです。

- 地図：**2 本指**で移動・拡大（1 本指はページのスクロールに使います）
- 写真：タップで拡大、**左右スワイプ**で送る
- タイトル・メモ：タップしてその場で編集

## 公開する

このアプリはサーバーを持たない静的サイトなので、置き場所は自由に選べます。

### A. GitHub Pages（リポジトリが public のとき・無料）

`.github/workflows/deploy.yml` が push を検知して自動でビルド・公開します。
公開先は `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

初回だけ、リポジトリの **Settings > Pages > Build and deployment > Source** を
**「GitHub Actions」** にしてください（Pages の有効化は管理者権限が要る操作で、
Actions のトークンからは行えません）。

> **private リポジトリでは GitHub Pages は有料プラン（Pro 以上）の機能です。**
> 無料で使うにはリポジトリを public にするか、下の B を選んでください。
> なお、写真はリポジトリに含まれず端末内にしか保存されないため、
> public にしても公開されるのはソースコードだけです。

対象ブランチは `main` と `claude/travel-memory-photo-service-ty988y` です。
ブランチを整理したときは、`deploy.yml` の `on.push.branches` を実際のデフォルトブランチに
合わせてください（GitHub Pages は既定でデフォルトブランチからのデプロイのみを許可します）。

### B. Cloudflare Pages / Netlify / Vercel（private のまま・無料）

いずれも無料枠で private リポジトリを HTTPS 配信できます。設定は共通です。

| 項目 | 値 |
| --- | --- |
| Build command | `npm run build` |
| Output directory | `dist` |
| Node version | 22 |

これらはサイトのルートに配置されるため、`BASE_PATH` の指定は不要です（既定の `/` のまま）。

### C. 公開せずに自分の端末だけで使う（無料）

開発サーバーは LAN からもアクセスできる設定になっています。

```bash
npm run dev
```

表示される `Network:` の URL（`http://192.168.x.x:5173/` など）を、
同じ Wi-Fi につないだ iPhone の Safari で開けば、そのまま使えます。

ただし `https://` ではないため、次の 2 つは使えません（写真の取り込み・地図・
時系列表示などの主要な機能は問題なく動きます）。

- Service Worker によるオフライン表示
- ホーム画面に追加したときの全画面表示

また PC の開発サーバーを止めると iPhone からは開けなくなります。
常時使いたい場合は A か B を選んでください。

## 使い方（ローカル）

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果の確認
npm run typecheck
```

サブパスで配信する場合（GitHub Pages など）は `BASE_PATH` を指定してビルドします。

```bash
BASE_PATH=/Trip-memory/ npm run build
```

## まとめ方の調整

うまく区切られないときは、画面右上の「設定」から変えられます。

| 設定 | 既定値 | 意味 |
| --- | --- | --- |
| 旅の区切り | 24 時間 | この間隔が空いたら別の旅にする |
| 立ち寄り先の区切り（時間） | 90 分 | この間隔が空いたら別の立ち寄り先にする |
| 立ち寄り先の区切り（距離） | 400 m | これ以上移動したら別の立ち寄り先にする |
| 地名を自動で取得する | オン | オフにすると座標のまま表示する |

## 構成

```
src/
  lib/
    types.ts      データ定義
    exif.ts       EXIF（撮影日時・GPS）の読み取り
    image.ts      縮小と内容ハッシュ
    importer.ts   取り込みパイプライン（HEIC 変換を含む）
    db.ts         IndexedDB（写真・地名キャッシュ・編集内容・設定）
    geo.ts        距離と重心の計算
    cluster.ts    旅／立ち寄り先の切り分けとタイトル生成
    activity.ts   場所の種別と時間帯から行動を推測
    geocode.ts    逆ジオコーディング（直列・1 秒 1 件・結果はキャッシュ）
    media.ts      Blob URL の管理
    store.tsx     アプリ全体の状態
  components/
    Uploader / TripList / TripDetail / MapView / Timeline / Lightbox /
    EditableText / SettingsPanel
```

## 制限事項

- 位置情報が付いていない写真は、時系列には並びますが地図には出ません
  （iPhone は「設定 > プライバシーとセキュリティ > 位置情報サービス > カメラ」で許可が必要です）。
- EXIF の撮影日時はタイムゾーンを持たないため、撮影地の壁時計の値としてそのまま表示します。
- 地名の取得は Nominatim の利用ポリシーに合わせて 1 秒に 1 件ずつ行うため、
  立ち寄り先が多いと表示までに少し時間がかかります（結果はキャッシュされ、2 回目以降は即座に出ます）。
- 保存先はブラウザの IndexedDB なので、ブラウザのデータを消すと写真も消えます。
  端末間の同期もありません（iPhone で入れた写真は iPhone の中だけにあります）。
- iOS Safari はしばらく使っていないサイトのデータを消すことがあります。
  取り込み時に「消さないでほしい」と登録しますが、ホーム画面に追加しておくとより残りやすくなります。
- HEIC の変換モジュールは約 3MB あり、HEIC を初めて取り込むときだけ読み込みます
  （2 回目以降はキャッシュから読み込まれます）。
